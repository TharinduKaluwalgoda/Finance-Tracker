# Finance Tracker

A clean, modern personal finance tracker built with **Next.js 15**, **Tailwind CSS v4**, and **Chart.js**.

## Features
- Track income and expenses with categories and dates
- Balance overview with income/expense summary cards
- Doughnut chart (financial overview) + Pie chart (expense categories)
- Monthly analytics with spending ratio bar
- Search and filter transactions
- Inline edit and delete
- Stats: total transactions, largest income/expense, average expense
- Export all transactions to CSV
- Light and Dark mode (persisted)

## Tech Stack
- Next.js 15 (App Router)
- Tailwind CSS v4
- Chart.js + react-chartjs-2
- Framer Motion
- DM Sans + DM Serif Display fonts

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```
